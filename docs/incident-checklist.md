# 🚨 Cyber Incident Response Quick Checklist

## 1. First Response

- [ ] Record the date and time of the incident.
- [ ] Identify the person reporting the incident.
- [ ] Identify the affected device or system.
- [ ] Notify the Incident Lead.
- [ ] Assign an initial severity level.
- [ ] Preserve relevant evidence.
- [ ] Isolate affected systems when appropriate.
- [ ] Protect unaffected systems.
- [ ] Protect backup infrastructure.

---

## 2. Detection and Analysis

- [ ] Confirm the security alert or report.
- [ ] Identify affected systems.
- [ ] Identify affected accounts.
- [ ] Review relevant security logs.
- [ ] Review endpoint alerts.
- [ ] Review authentication activity.
- [ ] Determine the likely initial access method.
- [ ] Determine whether the incident is still active.
- [ ] Determine whether sensitive data may be affected.
- [ ] Map confirmed behavior to MITRE ATT&CK when appropriate.

---

## 3. Containment

- [ ] Isolate affected devices.
- [ ] Check for additional affected systems.
- [ ] Disable compromised accounts when necessary.
- [ ] Block suspicious connections when appropriate.
- [ ] Protect unaffected systems.
- [ ] Protect backups.
- [ ] Record every containment action.
- [ ] Use an alternative communication channel if required.

---

## 4. Evidence Preservation

- [ ] Preserve security logs.
- [ ] Preserve authentication logs.
- [ ] Preserve endpoint alerts.
- [ ] Preserve network logs.
- [ ] Preserve relevant emails or messages.
- [ ] Record important timestamps.
- [ ] Document who collected each item.
- [ ] Restrict evidence access to authorized personnel.

---

## 5. Eradication

- [ ] Identify the initial access method.
- [ ] Remove unauthorized persistence.
- [ ] Reset compromised credentials.
- [ ] Patch exploited vulnerabilities.
- [ ] Remove unauthorized software.
- [ ] Rebuild compromised systems when appropriate.
- [ ] Verify security controls.
- [ ] Confirm the threat has been removed.

---

## 6. Recovery

- [ ] Identify critical services.
- [ ] Verify clean backups.
- [ ] Verify backup integrity.
- [ ] Prioritize recovery order.
- [ ] Restore critical systems.
- [ ] Restore additional systems in stages.
- [ ] Monitor restored systems.
- [ ] Confirm normal business functionality.
- [ ] Document recovery actions.

---

## 7. Communication

- [ ] Notify the Incident Lead.
- [ ] Notify the IT/Security Team.
- [ ] Notify management when required.
- [ ] Provide employees with approved instructions.
- [ ] Coordinate with Legal/Privacy when applicable.
- [ ] Assess external notification requirements.
- [ ] Use only verified information.
- [ ] Record important communications.

---

## 8. Lessons Learned

- [ ] Create the incident timeline.
- [ ] Identify the root cause.
- [ ] Identify contributing factors.
- [ ] Review what worked well.
- [ ] Identify response problems.
- [ ] Document security gaps.
- [ ] Assign corrective actions.
- [ ] Update security procedures.
- [ ] Update staff training.
- [ ] Update the incident response plan.

---

## 9. Incident Closure

- [ ] Incident contained.
- [ ] Threat eradicated.
- [ ] Systems recovered.
- [ ] Evidence documented.
- [ ] Required notifications completed.
- [ ] Lessons learned completed.
- [ ] Corrective actions assigned.
- [ ] Incident report completed.
- [ ] Incident officially closed.

---

# 🔐 Ransomware Quick Response

If ransomware is suspected:

**STOP → REPORT → ISOLATE → PRESERVE → CONTAIN → RECOVER → LEARN**

### STOP
Do not interact with suspicious files.

### REPORT
Immediately notify the IT/Security Team.

### ISOLATE
Isolate affected systems according to organizational procedures.

### PRESERVE
Protect relevant logs and evidence.

### CONTAIN
Prevent further spread and protect unaffected systems and backups.

### RECOVER
Use verified clean backups and restore systems in a controlled manner.

### LEARN
Document the incident and improve security controls.

---

## ⚠️ Important

This checklist is for authorized defensive incident-response activities.

Do not execute malware or destructive actions during training. Use controlled, non-destructive simulations.
